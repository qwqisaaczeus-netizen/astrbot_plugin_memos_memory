# v4.6.2：稳定版

`v4.6.2` 是当前推荐用于长期日常运行的稳定版本。它延续 4.6 的完整记忆生产、全 MEMORY 检索、注意力友好注入、滚动状态、时间、心潮、上下文治理和备份架构，并重点修正模型配置体验与预设安全边界。

## 这版适合谁

- 第一次安装插件。
- 已在使用 4.5.x，希望升级到成熟的 4.6 生产链。
- 重视长期稳定运行，不准备参与 5.0 Shadow 评测。

## 主要变化

- WebUI 的所有 Chat Completion Provider 字段使用 AstrBot 已启用模型下拉列表。
- 压缩、查询规划、Episode 提取、文学日记、滚动状态、画像、心潮、梦境和时间洞察更容易选择正确模型。
- 全局四档与召回实验室四档预设重新校准。
- 后端硬性保护手填字段：Token、URL、角色名、Provider ID、端口、路径、托管目录和 Tier 词表不会被预设覆盖。
- 保持 4.6 全 MEMORY 链路：原始对话、Episode、日记 passage、BM25、原始轮次和时间线索统一召回。
- 保持第一人称文学日记、滚动当前状态、心潮与严格时间边界。

## 升级

从 4.5.x 或 4.6.x 直接覆盖并重载即可。没有新的数据库 schema 变化，不需要执行 `/memos-reindex`。

只有在更换 Embedding 模型或向量维度时，才需要全量重建索引。

## 安全边界

- 不改写已有 Memos 日记。
- 不删除原文档案、Episode、滚动状态、画像或心潮状态。
- Release ZIP 不包含配置、Token、数据库或用户数据。
