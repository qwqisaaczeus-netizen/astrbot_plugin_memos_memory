# v5.0.0-test0：非破坏式记忆遗忘预览

这是 5.0 架构的第一个公开测试版。它以 `v4.6.2` 为完整基线，新增记忆可达性、线索救回、类型化干扰和回答使用证据，但固定运行在 Shadow 模式。

## 最重要的边界

**test0 不会改变真实召回和注入名单。**

5.0 会读取同一批候选、计算建议结果并记录差异；聊天仍由 4.6.2 的成熟链路决定。这个版本用于积累真实评测，而不是让未验证算法立刻接管长期记忆。

## 新增能力

- 每篇记忆维护持久性、鲜明度、独特性、证据加成、干扰负载、抑制与自然可达性。
- 使用鲜明、潜伏、深层三态描述访问难度，并用迟滞避免阈值抖动。
- 日期、人物、物件、原话和稀有检索词形成线索签名。
- `2022-03-14` 与 `2022年3月14日` 等格式统一归一化。
- 明确线索可形成深层救回建议；“你还记得吗”之类弱泛问不会自动突破。
- 区分同事件复述、同主题不同事件、矛盾阶段、因果链和表面词汇相似。
- 记录候选、正式入选和回答实际使用之间的差异，为后续再巩固提供证据。
- 新增独立 `/access` 工作台、可点击干扰图、记忆剖面和 Shadow 对照实验。

## 数据迁移

- `episodic_memory.db` schema 从 6 升到 7。
- 首次升级前自动创建本地快照。
- 新增 `memory_access_*` 与 `memory_interference_*` 派生表。
- 不改写 Memos、日记、原文、Episode、滚动状态、画像、时间或心潮。
- 新派生表损坏或维护失败时，当前请求 fail-open 回到 4.6.2。

## 安装与升级

从 `v4.6.2` 直接覆盖并重载即可，无需执行同步、重索引或重建命令。启动后后台会从现有 Episode 回填可达状态。

如果只想稳定使用而不参与测试，请继续选择 `v4.6.2`。
