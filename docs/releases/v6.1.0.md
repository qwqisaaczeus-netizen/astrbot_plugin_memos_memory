# v6.1.0 · 清蓝工作台与受控记忆生产

6.1.0 基于 RC6 A 测试修正版，整合统一工作台、证据解释核验、选择性文学写作和任务恢复。保留既有检索、注入、时间、心潮与小院职责，安装不会自动重跑旧作业或启用新日记生产。

## 主要更新

- **清蓝工作台**：总览、心潮、月历、记忆生产、模型调度、补偿和控制台共享视觉系统；成功、警告、错误与未启用状态分别呈现。注入构成支持聚焦明细，月份柱条读取真实统计，同日多篇和空日明确显示。
- **证据解释核验**：精确引文之后核对人物归属、意图、动作完成状态与时间关系。保留原解释和修正记录；不确定解释不能直接用于日记事实绑定。
- **选择性文学写作**：新 `literary-v4` 区分正文精确关联、背景参考和证据库留存。完整证据保留；关联 ID 数量不再冒充正文覆盖率。
- **中文证据检索**：词面投影同时使用解释与原始引文，改善中文专名和原话检索。派生词面重建不改事实、日记正文或原文位置，也不重新生成 Embedding。
- **模型调度与恢复**：任务主模型、跟接、流式、思考模式、输出预算和超时可见；旧作业保留冻结合同与费用历史，恢复已保存结果不等于重新运行整条生产链。
- **A 测试兼容修正**：收紧 owned 覆盖、引用定位和事实 ID 校验；已返回但被拒收的结果可重新本地校验，减少因兼容性修正导致的重复请求。超容量明确停止，不静默截断事实。

源码与实现说明：[RC6](../../DESIGN_610_RC6.md)、[A 测试修正](../../DESIGN_A_RC6_FIX.md)、[清蓝工作台](../../DESIGN_610_CLEAR_BLUE.md)。

## 安装升级

1. 备份插件配置、本地原文与数据库，以及 Memos 数据。
2. 安装本 Release 的 `astrbot_plugin_memos_memory-6.1.0.zip`，重载插件并强制刷新 WebUI。
3. 检查版本、数据数量、模型路线和未完成任务。普通覆盖升级无需同步、重索引或重写历史日记。
4. 需要新生产时，先在 `/production` 生成并检查草稿，再显式确认费用、备份和 Memos 的固定 ID / 事件日期发布能力。

从 5.x / 6.0 升级可能补建本地派生层；这不是全程只读，也不表示自动改写历史 Memos 正文。首次接入未同步资料或更换 Embedding 模型/维度时的操作见 [安装说明](../installation.md)。

## 已知边界

- 新日记生产默认关闭，Memos 发布能力确认默认关闭；已有草稿不会因安装或启用新链而自动发布。
- 自动新生产每批默认最多 12 次物理模型请求，草稿入口默认 8 次，包含重试与跟接；次数上限不等于篇数、并发或免费额度。
- 解释核验和模型审稿仍是机器判断。引文匹配不保证解释正确，正文片段存在不保证文学质量。
- 既有 ACCESS 默认 `supplement`，在主召回后最多补充 T/A 两槽；完整遗忘排序器没有接管主名单。脉络和一致性观察默认 Shadow。
- 旧作业不自动升级合同或重跑；恢复、重写、发布及补索引的费用与写入范围以界面确认和作业记录为准。
- 本 ZIP 不包含 7.1 RC 的更新机制，不覆盖 AstrBot 核心，也不包含用户数据库、私有配置或测试原文。
- Live2D 核心由浏览器运行时加载外部资源；该资源不可用时保留静态/网格渲染回退，记忆链路继续独立工作。
